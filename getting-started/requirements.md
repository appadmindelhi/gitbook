# Requirements & Compatibility

### Shopify plan

UpsellSuite works on all Shopify plans that support theme app embeds and app proxies (Basic Shopify and above, including Shopify Plus).

### Theme compatibility

UpsellSuite uses the standard **theme app extension** embed mechanism, which is compatible with Online Store 2.0 themes. If your theme was built before OS 2.0 and hasn't been upgraded, the app embed toggle may not be available in your Theme Editor.

Once the embed is on, Product-page offers appear automatically right below "Add to Cart" — no theme edits needed. If you want to move an offer elsewhere on the page, most OS 2.0 themes support dragging the "UpsellSuite Offer" app block into place in the Theme Editor. For themes that don't support app blocks (or for fully custom placement), UpsellSuite provides a manual HTML snippet you can paste anywhere in your product template — see [Product-Page Placement](../app-overview/product-page-placement.md).

### Checkout / Post-purchase

Post-purchase (one-click upsell) offers require your store's checkout to support post-purchase extensions. This is a native Shopify checkout capability and does not require Shopify Plus.

### Multi-currency & localization

- Offers display correctly in the shopper's presentment currency.
- Offer copy (title, badge, button text, discount labels) can be translated per store locale.

### What UpsellSuite does not require

- No custom theme code changes for the default placement — the one-time app embed toggle is enough.
- No separate app for post-purchase or thank-you-page offers — they're built into the same Offer Builder.
- Manual code editing is only needed if you choose to reposition a Product-page offer on a theme that doesn't support app blocks — see [Product-Page Placement](../app-overview/product-page-placement.md).
